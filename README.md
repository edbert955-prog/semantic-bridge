# Semantic Bridge GitHub Kit

Kit ini berisi panduan push source project Laravel ke GitHub dan ringkasan diagnostik reasoner. Kit ini **bukan keseluruhan source project** dan tidak mengklaim reasoner sudah diperbaiki.

Isi:
- `gitignore_recommended.txt` — aturan `.gitignore` yang disarankan untuk digabung dengan aturan existing project.
- `GITHUB_PUSH_GUIDE.md` — langkah PowerShell untuk inspeksi, commit, dan push.
- `REASONER_STATUS.md` — rangkuman fakta debugging yang aman dimasukkan ke issue GitHub.
